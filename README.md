# سادة البناء | Master Builders

<p align="center"><b>لعبة استراتيجية لوحية: اجمع الموارد، عيّن المتدربين، شيّد المباني، وارتقِ بالكاتدرائية قبل خصومك.</b></p>

## ⬇️ التحميل

**[حمّل آخر نسخة لويندوز (MasterBuilders-Setup.exe)](https://github.com/AshrafKotb/master-builders-releases/releases/latest/download/MasterBuilders-Setup.exe)**

1. شغّل الملف. لو ظهر «Windows protected your PC»، دوس **More info** وبعدين **Run anyway** (الملف مش موقّع بشهادة مدفوعة).
2. اختار اللغة وكمّل التثبيت. مش محتاج صلاحيات أدمن.
3. هتلاقي اللعبة على سطح المكتب وفي قائمة Start.

**التحديثات بتوصل لوحدها:** اللعبة بتتأكد من وجود نسخة جديدة كل ما تفتحها، وبتعرض عليك تحدّث بضغطة واحدة.

محتاج ويندوز 10 أو 11 (64-bit).

---

**Download for Windows:** [MasterBuilders-Setup.exe (latest)](https://github.com/AshrafKotb/master-builders-releases/releases/latest/download/MasterBuilders-Setup.exe). Updates install themselves from inside the game. Windows 10/11, 64-bit.
